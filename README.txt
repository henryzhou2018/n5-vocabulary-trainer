JLPT N5 Vocabulary Trainer — iPhone Web App

Vocabulary: 528 entries migrated from Windows v3.

IMPORTANT: To install on iPhone, upload this folder to an HTTPS website. Opening index.html from the iPhone Files app is NOT equivalent to a hosted PWA and may prevent offline installation.

Simple free hosting: GitHub Pages (repository -> Settings -> Pages -> deploy from branch), Netlify Drop, or Cloudflare Pages.
Open the HTTPS link in Safari -> Share -> Add to Home Screen.
Then launch the installed app once while online to cache the files.

Japanese audio uses speechSynthesis (device voice). Tap Start or Speak to activate; iOS may limit autoplay, especially with screen locked or silent mode.

Files: index.html, app.js, words.js, manifest.webmanifest, sw.js, icons. No Python required.
